## Features
- **Interactive Audio Player**: Dynamic, client-side HTML5 player with continuous autoplay, reciter options, speed controls, and volume configurations.
- **Search & Filters**: Instant client-side search by Surah name, translation, or number, with filters for Meccan and Medinan Surahs.
- **Bilingual Translations**: High-fidelity side-by-side English (Sahih Intl) and Bangla (Muhiuddin Khan) translations.
- **Typography Comfort**: Custom size sliders for Arabic script and translations to match reader preferences.
- **SEO & Social Share Ready**: Complete Open Graph, Twitter metadata, dynamic XML sitemaps, and robots configuration.
- **Modern Responsive Design**: Fluid glassmorphism elements, micro-animations, and full dark-theme diacritics layout preservation.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

Compile TypeScript and build static route pages:

```bash
npm run build
npm run start
```
